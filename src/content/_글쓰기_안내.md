# NaksuGames 블로그 글쓰기 안내 (Obsidian)

이 폴더(`src/content`)는 Obsidian 보관함입니다. 이름이 `_`로 시작하는 파일은 사이트에 올라가지 않습니다.

## 처음 한 번
1. Obsidian을 설치합니다.
2. 이 저장소를 내려받고 `write` 브랜치로 바꿉니다.
3. Obsidian → 보관함 열기 → `src/content` 폴더를 고릅니다. "제작자 신뢰·플러그인 사용"에서 예를 누릅니다.

## 글 쓰기
- 왼쪽 위 집 아이콘(Home Base)을 누르면 글 목록이 나옵니다. 새 글 버튼을 누르고 제목을 쓰면 `posts/` 폴더에 글이 생깁니다.
- 위쪽 속성 칸: 제목(title), 날짜(published), 한 줄 소개(description), 태그(tags), 분류(category), 대표 그림(image).
- 새 글은 `draft: true`(초안)로 만들어집니다. 다 쓰면 draft를 끄세요(false).
- 그림은 끌어다 놓으면 글 옆 `attachments` 폴더에 들어갑니다.
- 유튜브 영상은 공개된 영상만 넣습니다.

## 올리기
- 오른쪽 아래 버튼 또는 `Cmd+Shift+S`(Windows는 `Ctrl+Shift+S`)로 저장·동기화하면 `write` 브랜치에 올라갑니다.
- `write`에 올라온 글은 보안 검수(실명·내부 경로·비밀값·다른 게임 언급 등)를 통과한 뒤에만 실제 사이트에 게시됩니다. 통과 또는 고칠 점은 텔레그램으로 알려 드립니다.
