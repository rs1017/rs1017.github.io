# NaksuGames 소개

19년차 게임 서버 개발자로, 지금도 현업에서 일하고 있습니다.

나이 먹고 은퇴하면 AI와 함께, 퀄리티는 조금 떨어지더라도 인디 게임을 직접 만들고 출시하는 것이 목표입니다. NaksuGames는 그날을 위해 지금부터 초석을 놓는 곳입니다.

첫 번째 프로젝트 이름은 **나키온의 모험**입니다. 가족들과 반려동물을 가상 인물로 만들어 게임 속에 넣었습니다.

코드는 AI와 함께 쓰고, 무엇을 넣고 뺄지는 직접 고민하고 결정합니다. 개발 과정과 바뀐 점, 플레이 영상을 이곳에 정리해 올립니다. 영상은 [유튜브 채널 낙수아빠](https://www.youtube.com/@naksupapa)에서도 볼 수 있습니다.
